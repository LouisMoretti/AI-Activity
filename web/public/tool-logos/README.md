# Tool marks

The dashboard keeps these logos local so profile views do not request them from
third-party hosts at runtime.

- `claude.svg`: Claude mark from [Simple Icons](https://github.com/simple-icons/simple-icons), based on the Claude brand mark.
- `codex.svg`: Codex mark from [LobeHub Icons](https://github.com/lobehub/lobe-icons).
- `opencode.svg`: OpenCode mark from [Simple Icons](https://github.com/simple-icons/simple-icons), based on the OpenCode logo.
- `antigravity.png`: full-color Antigravity icon from [Google's press assets](https://antigravity.google/press).

The monochrome SVGs are shown in white to keep their official silhouettes
legible on the dashboard's dark surfaces. Tool names and marks remain the
property of their respective owners; AI Activity is not affiliated with them.
